融的小小關心所｜互動網頁 v4.0
====================================

一、更新順序：先後台，再網站
1. 從原本收回覆的 Google 試算表 →「擴充功能」→「Apps Script」。
2. 用本包 Code.gs 取代原程式並儲存。初次設定或更換試算表時，選 setupBackend 執行一次並完成授權；沿用已設定的原試算表者可保留設定。
3.「部署」→「管理部署作業」→ 編輯原網頁應用程式 → 版本選「新版本」→「部署」。
4. 執行身分維持「我」，存取權維持「所有人」。沿用原部署以保留 /exec 網址；若另建部署，須同步修改 index.html 的 SCRIPT_URL。
5. 後台部署完成後，再更新 GitHub Pages 的 index.html、photo-ikea-20261025.jpg、scrapbook-stickers.png，三個檔案皆放同一層。
6. 等候 Pages 更新，按 Ctrl+Shift+R 重新整理。心情或地點送出後，取得後台確認才代表收到。

只儲存 Code.gs 不會更新公開部署。新版心情與共用地點都需要此版後台，請先完成後台部署再更新 HTML。
Code.gs 不需上傳 GitHub；README.txt 可留作本機維護說明。本包未自動變更你的線上部署。

二、頁面內容
- 移除原本「嗨 kk 小朋友」首頁與四張單人照片堆疊，改由 IKEA 合照的相片旅程開場。
- 使用內建圖像工具生成的小狗與雪人剪貼貼紙，新增共用「想去的地方」清單；交付包另附素材生成說明。
- 六張心情卡：心情美麗、平平淡淡、有點累了、心情不好、有點煩惱、想找你聊聊；點一次直接展開小信，以一個返回按鈕回到心情卡。
- 保留「03 / POCKET-SIZED SUNSHINE」、24 張鼓勵紙條與 6 張關心小卡。
-「經期小本子」改成直接顯示的小月曆，只有開始與結束兩個主按鈕，沒有日期輸入欄、設定、歷史清單或儲存提示文字。

三、共用地點與心情
-「想去的地方」送出後存入 Google 試算表，換裝置或重新開啟網站仍可讀取；其他開啟網站的人也會看到。
- 地點限制 60 字，顯示最近 50 筆，由新到舊排列；另外儲存在「想去的地方」工作表，三欄為提出時間／想去的地方／請求 ID。
- 心情仍使用「回覆紀錄」四欄：送出時間／選擇狀態／想說的話／請求 ID；既有資料不改寫，不需重建試算表。
- 後台保留六種舊工作狀態：要去上班了、還在上班、準備下班、下班了、午休吃飯、準備開會，更新期間舊網頁仍可使用。
- 兩種表單的收件與錯誤快取分開；失敗保留草稿與請求 ID，重送不重複新增同一紀錄。

四、小月曆的使用
- 預設選取台灣時間的今天。按「今天經期來了」記錄開始，當天顯示第 1 天；重複按同一天不會新增重複紀錄。
- 要補登時，先點月曆上的實際開始日，再按「這天經期來了」。月曆可切換過往月份，未來日期不能選。
- 點選實際結束日後按「經期結束了」，結束最近一筆符合日期的未結束紀錄。已記錄日期以粉色呈現，預估日使用空心外框。
- 依使用者已確認的 28 天週期，以最新實際開始日加 28 天顯示「下次預估」日期。預估日到了也不會自行新增實際紀錄；沒有排卵、安全期等推算。
- 日期紀錄僅存在目前瀏覽器、目前網站來源的 localStorage（kk-period-diary-v1），不傳到 Google 試算表，也不放在公開原始碼。
- 本機預覽紀錄不會跟著上傳到正式網站。正式網址首次開啟後，請從小月曆補登先前提供的實際開始日一次；往後可在開始當天直接按主按鈕。
- 換瀏覽器、換裝置、換網站網址或清除網站資料後，不會自動帶入原紀錄。瀏覽器拒絕儲存時會顯示未保存，不會假稱成功。
- 週期計算定義參考 NHS：https://www.nhs.uk/conditions/periods/fertility-in-the-menstrual-cycle/

五、問題排查與維護
- 新選項或共用地點無法送出：檢查 Code.gs 是否已部署「新版本」，以及 SCRIPT_URL 是否指向該部署的 /exec。
- 收件服務未連上留言簿：從原試算表執行 setupBackend，再部署新版本；等不到確認時查看網路、部署存取權及 Apps Script「執行項目」。
- 固定錯誤代碼：UNSUPPORTED_CHOICE（選項未支援）、INVALID_REQUEST（格式不符）、SPREADSHEET_NOT_CONFIGURED（未連結試算表）、WRITE_FAILED（心情寫入失敗）、INVALID_PLACE（地點格式不符）、PLACE_WRITE_FAILED（地點寫入失敗）。
- health 只回傳版本、支援選項、ready／code 與 features.places=true，不公開試算表 ID、名稱、留言或本機經期日期。
- GET 不建立工作表；後台寫入只用 POST。地點清單只回傳 id／place／createdAt，前端以純文字呈現。
- 改 HTML／圖片需更新 Pages，改 Code.gs 需重新部署；圖片須與 index.html 同層，名稱與大小寫一致。
